# HerFirst frontend

This is the React + TypeScript frontend powered by Vite. For setup, Windows startup scripts, backend configuration, test commands, and troubleshooting, see the project-root `README.md`.

The development server is configured for `http://localhost:5174/`. Install the locked dependencies with `npm.cmd ci` and run `npm.cmd run dev` from this folder. Node.js 20.19+ or 22.12+ is required by Vite 8.
